**交付範疇**（依 RFP P1 節錄版）:

| 項目 | 說明 |
|------|------|
| 單一骨架 | 採 Single Skeleton + State Machine + Slot System |

| 命名規範對照 | 截圖驗證，須與命名手冊 v1.0 完全一致 |

**驗收條件**（全數通過後支付尾款 70%）:
- B-1 hp_level 三段離散切換正確
- B-2 clean_level 三段離散切換正確

- B-4 臉部元素在體型變動時比例固定
- B-5 三種 Idle 循環完整且無縫
- B-6 快速變量測試無破面
- B-7 命名規範截圖完整，與命名手冊 v1.0 一致
