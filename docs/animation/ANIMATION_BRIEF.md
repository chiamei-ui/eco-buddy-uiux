## 一、專案背景

ECO Buddy 是 ECOCO App 內的養成遊戲模式。用戶透過現實回收行為累積角色體力，透過 App 互動累積心情值，不同數值組合會觸發不同的角色「狀態」。

Phase 1 為快閃封測階段，測試用戶對「角色狀態收藏」機制的反應。本文件列出 Phase 1 所有動畫規格，供前端整合與 PM 確認。

## 三、9 個狀態規格

### 狀態 01：瀕死邊緣（體力低 × 潔淨低 × 心情低）

- **視覺描述**：虛弱倒地、髒亂、表情無神
- **海龜造型**：龜殼髒污、四肢無力外翻、紅帽歪掉、表情昏迷
- **情緒關鍵字**：SOS、可憐、需要救援

### 狀態 07：潔癖徹底（體力低 × 潔淨高 × 心情低）

- **視覺描述**：消瘦但極度乾淨、緊張神經質
- **海龜造型**：殼擦得發亮、四肢用毛巾擦拭、表情緊繃
- **情緒關鍵字**：潔癖、神經質、過度清潔

### 狀態 08：高冷貴婦（體力高 × 潔淨高 × 心情中）

- **視覺描述**：圓潤豐滿、毛色光亮、戴墨鏡、優雅貴氣
- **海龜造型**：龜殼光亮如寶石、戴墨鏡（紅帽下方）、坐姿翹腿
- **情緒關鍵字**：高冷、貴氣、優雅

### 狀態 13：生活壓力（體力中 × 潔淨中 × 心情低）

- **視覺描述**：上班族 OL 風格、被文件淹沒、表情崩潰
- **海龜造型**：龜殼上堆滿文件、四肢無力打電腦、表情厭世
- **情緒關鍵字**：加班、過勞、社畜感

### 狀態 17：都市精英（體力中 × 潔淨高 × 心情低）

- **視覺描述**：西裝筆挺、坐高背扶手椅、外光內疲
- **海龜造型**：紅帽 ＋ 西裝領帶、坐辦公椅、爪子搭扶手
- **情緒關鍵字**：菁英、城府、外光內疲

### 狀態 26：雍容華貴（體力高 × 潔淨高 × 心情中）

- **視覺描述**：戴金色皇冠、坐金色寶座、背景紋飾華麗
- **海龜造型**：龜殼鍍金紋路、頭戴皇冠、坐金椅
- **情緒關鍵字**：富貴、奢華、皇室

### 狀態 30：芝芭大舞（體力中 × 潔淨中 × 心情極高）

- **視覺描述**：愛心眼睛、彩虹背景、四肢張開歡呼
- **海龜造型**：四肢張開跳舞、眼睛變愛心、嘴開大笑
- **情緒關鍵字**：開心爆表、慶祝、舞蹈

### 狀態 32：彩虹之神（體力高 × 潔淨高 × 心情高）— 傳說態

- **視覺描述**：全身彩虹漸層發光、神性光暈、最稀缺的傳說狀態
- **海龜造型**：龜殼彩虹漸層、身體散發光暈、表情神聖平靜
- **情緒關鍵字**：神性、傳說、極致、稀有

### 狀態 34：科技武裝（體力中 × 潔淨高 × 心情中）— 特殊型態

- **視覺描述**：機甲鎧甲、賽博龐克風、未來感
- **海龜造型**：龜殼變成機甲外殼、四肢穿裝甲、紅帽改成科技頭盔
- **情緒關鍵字**：科技、未來、武裝、酷

## 四、Rive 動畫技術規格

每個狀態包含兩種動畫（Phase 1 主包）：

### Idle Loop

| 項目 | 規格 |
|------|------|
| 時長 | 低心情 5 秒 / 中心情 4 秒 / 高心情 3 秒（固定循環） |
| 內容 | 呼吸起伏 ＋ 眨眼（3–7 秒隨機）＋ 四肢輕微擺動 |
| 用途 | P1 主展示 / P12 補充站結果頁背景 |

### 點擊反應

| 項目 | 規格 |
|------|------|
| 時長 | 0.5–1.5 秒 |
| 觸發 | 用戶點擊角色（每日上限 10 次，超過後仍播放） |
| 內容 | 依狀態個性設計（歪頭 / 跳一下 / 揮手等） |
| 結束 | 播完自動回 Idle Loop，禁止硬切 |

### 本次不做（另案採購）

- 餵食動畫（9 個狀態共用）
- 道具使用動畫（4 支）
- 變身過渡動畫

## 五、交付格式與檔案規範

### 規格

| 項目 | 規格 |
|------|------|
| 設計畫布 | 1024×1024px |
| App 顯示尺寸 | 120×120px |

### 每個狀態交付清單

| 格式 | 用途 |
|------|------|
| `.riv` | 主要整合檔，Rive runtime 使用 |
| `.mp4` | 10 秒預覽影片（idle ＋ 點擊反應），驗收用 |
| `.png` 靜態縮圖 | App 圖鑑 / 小尺寸顯示 |
| `.png` 設計稿 | 高解析透明背景，前端備用 |

### 命名規則

```
ecobuddy_turtle_[狀態編號]_[英文狀態名].[副檔名]
```

範例：
```
ecobuddy_turtle_01_dying.riv
ecobuddy_turtle_01_dying.mp4
ecobuddy_turtle_01_dying.png
```

### 檔案入庫規則

- `< 5MB` → 直接進 `assets/animations/`
- `≥ 5MB` → 上傳雲端，ANIMATION_LIST.md「檔案位置」欄填連結
