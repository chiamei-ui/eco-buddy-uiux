## D — 現實行為 → 回收餵食 Loop（HP 驅動）

```
♻️ 回收機台投瓶
  → 機台結算（投入數 / 退瓶數）→ 機台螢幕產生 QR Code
  → 📷 P2 統一掃碼（自動偵測 machine_type = recycling）
  → 🎁 P2b 本次回收結果頁
      ├─ 本週配額未用完 → 顯示食物 + HP + 下週食物預告
      │     ├─ 立即餵食 → P3 餵食流程
      │     └─ 存入食物欄 → 返回 P1（食物欄 +N · 入場動態：新增格光暈 + Badge pop + Buddy 泡泡）
      └─ 本週配額已用完 → 顯示「本週食物已領完」+ HP + 下週食物預告
            └─ 完成 → HP 計入 + 返回 P1
```

### 各節點說明

**REAL WORLD — 回收機台投瓶**
- 用戶至機台投入瓶罐
- 機台結算：顯示**投入數**與**退瓶數**
- 機台螢幕產生 QR Code

**P2 — 統一掃碼**
- 開啟相機，對準任何機台螢幕 QR Code
- 解析成功 → 後端解析 `machine_type`，路由至對應結果頁：
  - `recycling` → P2b 回收結果頁
  - `refill` → P12 補充站結果頁
- 解析失敗 → 頁面提示「無法辨識，請對準機台螢幕」，繼續等待

**P2b — 本次回收結果頁**（掃碼成功後彈出）

換算規則（#3 v2 定案，2026-05-29）：

收瓶機：
| 投入物 | 體力 | 潔淨 |
|--------|------|------|
| PET 寶特瓶 / 鋁罐 / HDPE 牛奶瓶（進瓶） | +2 / 個 | +2 / 個 |
| PP 塑膠杯（進瓶） | +1 / 個 | +2 / 個 |
| 退瓶（任何品項） | — | -1 / 個 |

電池機：
| 投入物 | 體力 |
|--------|------|
| 1號 / 2號乾電池 / 9V 方形乾電池 | +10 / 顆 |
| 3號至6號乾電池 | +5 / 顆 |

頁面內容：
- **配額未用完**：食物種類與數量 + HP 值
- **配額已用完**：僅顯示 HP，提示「本週食物已領完」
- **ℹ️ 換算說明**（摺疊區）：公開公式，不糊主畫面（#19 定案）
- 常態顯示下週食物預告（週日 12:00 起）

操作按鈕：
- **配額未用完**：`先放食物欄`（→ P1，觸發食物欄入場動態）
- **配額已用完**：`完成`（→ P1，體力計入）

> **#22 定案**：移除「馬上餵 Buddy」按鈕；食物統一先存入食物欄，於 P1 拖曳完成餵食。

**P3 — 餵食流程（#22 決策：此獨立頁面已廢除）**

> 餵食改為 P1 原地完成：用戶將食物格拖曳至角色 → P1 原地播放餵食動畫 → 體力更新。

餵食動畫規格（P1 原地播放，另案採購）：
```
Idle → 轉身(0.3s) → 伸手(0.5s) → 拿取(0.4s) → 吃入(0.5s) → 滿足(0.8s)
```

**RESULT — 數值更新**
- HP 上升
- 角色外觀即時變化
- 進化狀態重新判斷
- 返回 P1 首頁

### 食物欄說明（P1 食物格）

食物採**每週配額制**（#20 定案）：
- **每種食物每週上限 5 個**
- **週三 12:00 重置**（午間重置觸發午休後投瓶）
- **週日 12:00 開始顯示下週食物預告**（提前 3 天）
- 配額用完 → 僅加體力，不產生食物
- 下週食物種類由運營手動排程

| 格狀態 | 視覺 | 可互動 | Badge |
|--------|------|--------|-------|
| **有庫存** | 橘色高亮邊框 | ✅ 可餵食 | 累積存量（上限 12）；每次餵食 -1 |
| **庫存低** | 半透明灰 | ✅ 仍可餵 | 顯示剩餘數量 |
| **🔒 未解鎖** | 虛線灰 | ❌ 鎖定 | 隱藏 |

## D2 — 現實行為 → 補充站購買 Loop（HP + 潔淨度驅動）

> **設計原則**：補充站掃碼只呈現「消費結果」，金流發生在現實，App 不涉及支付。
> 遊戲模式中唯一含金流的畫面為 **P4 商店**。

```
🩵 補充站現實消費（用戶已在實體補充站購買洗劑）
  → 機台螢幕產生 QR Code
  → 📷 P2 統一掃碼（自動偵測 machine_type = refill）
  → 🎁 P12 洗劑消費結果頁（HP ↑ + 潔淨度 ↑ 雙數值回饋）
  → 返回 P1
```

### 各節點說明

**REAL WORLD — 補充站現實消費**
- 用戶至補充站（ECOCO 實體據點）**已完成購買洗劑**
- 機台螢幕產生 QR Code（帶入本次消費場次資料）

**P2（refill 路徑）— 補充站掃碼**
- 同一掃碼頁，QR code 解析後 `machine_type = refill` 觸發此路徑
- 頂部標示依偵測結果動態顯示「補充站」或「回收」，給用戶視覺確認
- 解析成功 → 帶入場次資料，跳轉 P12

**P12 — 洗劑消費結果頁**（掃碼成功後顯示，結構對齊 P2b）

換算規則（#3 定案）：每消費 NT$10 = 體力 **+10** + 潔淨 **+10**

頁面內容：
- 顯示本次消費獲得的**體力值**與**潔淨值**
- 角色 Idle 動畫持續播放（不新增動畫 state）
- 下方並排：精神條（左）+ 清爽條（右），同步計數遞增動畫
- **ℹ️ 換算說明**（摺疊區）：公式 NT$10 = +10 精神 + +10 清爽，不糊主畫面（#19 定案）
- 動畫結束後：顯示「返回首頁」按鈕
- **進化判斷時序**：計數動畫結束後再判斷，不與動畫同步觸發

## G — P4 商店（課金驅動）

```
🛒 P4 商店  →（確認購買）→  💳 購買確認 Modal  →（購買成功）→  加入 P9 背包
```

### P4 商店說明（雙軌制 #16/#17 定案）

**【愛心（ECOCO 點數）消費區】**
- 基礎食物補給包
- 一般道具（逗貓棒 / 小球 / 梳子 / 零食）
- 清潔用品

**【真實金流 IAP 區】**
- 月底衝刺禮包 NT$199
- 月度通行證 NT$149
- 稀有限定裝飾（永久穿戴）
- 圖鑑加速 / 特殊道具

**規則**：點數與現金不互換、不互買；每個商品明確標示「💎 愛心」或「💳 NT$」

頁面設計：
- 分類 Tab 橫向滾動（食物 / 玩具 / 裝扮 / 氣氛…）
- 右上顯示愛心餘額 → 點擊展開來源底部 sheet（回收次數、補充站消費、任務獎勵）
- **月底衝刺禮包**：22–28 日置頂 · 倒數天數 · 樣式區隔一般卡
- 道具卡 Grid：2 欄排列，卡片顯示品名、效果、愛心 / NT$ 價格
  - 售罄 → 半透明灰 + 「Buddy 已經吃過了」標籤 · 不可點擊
- 道具卡點擊 → 購買確認 Modal（底部 sheet）

### 購買流程
- 愛心扣除 or Apple / Google Pay
- 愛心不足 → Modal 自動高亮現金支付選項
- 確認 → 道具加入 P9 背包
- 道具庫存 +1 · P1 道具包 Badge 更新

## J — 三維數值 → 進化狀態系統（全系統 36 種 · Phase 1 實作 9 種）

### 數值來源

| 數值 | 現實行為 | 外觀影響 |
|------|----------|----------|
| 體力 | 回收機台投瓶（依品項）· 食物欄餵食 · 補充站消費 | 體型大小 / 豐潤度 |
| 潔淨 | 回收機台進瓶 +2/個、退瓶 -1/個 · 補充站消費 | 龜殼光澤 / 純淨度 |
| 心情 | App 互動（廣告）· 道具使用 · 觸碰角色 | 表情 / 腮紅 / 動作活潑度 |

### 進化狀態矩陣（完整系統）

```
HP（高H / 標M / 低L）
  × 潔淨（高H / 標M / 低L）
  × 心情（MAX / 高H / 標M / 低L）
= 最多 36 種型態
```

### Rive 動畫規格（D2 · Phase 1 主包）

每個狀態必須包含：

| 動畫類型 | 規格 | 備註 |

## L — 月度週期總覽

**每月完整 Loop — 用戶旅程時間軸**

```
月初 1 日
  → 每日 Loop
  → 每週 Loop
  → 月底 -5 天
  → 月末選擇
  → 結算 +3 天
  → 下月 1 日
```

| 節點 | 事件 |
|------|------|
| **月初 1 日** | 新月度角色解鎖 · 新食物四格開始 · 月度任務重置 |
| **每日 Loop** | 開 App → 查角色 · 回收機台 → 掃碼 · 餵食 / 廣告開箱 · 任務簽到 |
| **每週 Loop** | 累積 5 次回收 · 累積 10 次餵食 · 領取週獎勵 · 食物四格集滿 |
| **月底 -5 天** | 圖鑑 Banner 出現 · 倒數提示開始 · 衝刺禮包上架（P4）· 月度任務最後衝刺 |
| **月末選擇** | P10 彈窗觸發 · 選本月最佳狀態 · 鎖入年度圖鑑 · 或系統自動挑最高分 |
| **結算 +3 天** | 仍可進 P10 修改 · 需消耗更換次數 · 未選 → 系統自動填入 |
| **下月 1 日** | 年度圖鑑新增 1 格 · 舊角色進圖鑑存檔 · 新角色登場 |
