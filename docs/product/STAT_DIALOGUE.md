# 數值 Icon 對話框文案範本

點擊數值 icon 後，由角色對話框跳出 icon 說明與當前數值對應文案。

---

## HP 生命值
> 驅動行為：帶禮物回家 · 補充站消費

| 狀態 | 觸發條件 | 文案 |
|------|----------|------|
| 高   | HP ≥ 70% | 「今天帶禮物回家，我整個活起來了！💪」 |
| 中   | HP 30–69% | 「有點累… 去補充站補個能量吧？」 |
| 低   | HP < 30% | 「快沒力了！帶禮物回家給我補能量 😫」 |

---

## 錯誤操作 / 邊界狀況對話框

> 系統錯誤或邊界行為發生時，由角色對話框取代冷冰冰的 toast/alert，維持遊戲沉浸感。

---

### 掃碼相關（P2）

> 此畫面無角色，改用系統 toast，語氣中性。

| 狀況 | 觸發條件 | 文案 |
|------|----------|------|
| QR Code 無法辨識 | 模糊 / 距離過遠 | 無法辨識 QR Code，請靠近後重新掃描 |
| QR Code 已過期 | 機台碼逾時 | QR Code 已過期，請重新至機台取碼 |
| QR Code 重複使用 | 同一碼掃第二次 | 此 QR Code 已使用，無法重複掃描 |
| 相機權限未開啟 | 系統拒絕相機存取 | 請至系統設定開啟相機權限 |
| 網路連線失敗（掃碼驗證） | API 無回應 | 網路連線失敗，請確認連線後再試 |

| 狀態 | 觸發條件 | 文案 |

| 正常格 | 有效期 >24h | 「拖到我身上，記得今天就用掉喔！」 |

| 已過期格 | 有效期 ≤0 | 「嗚… 這個不見了 😔」（不觸發任何操作） |

### 新手引導（首次進入 P1）

| 狀況 | 觸發條件 | 文案 |
|------|----------|------|
| 新手首次進入遊戲，引導餵食 | `showTutorial` 完成或跳過後 400ms | 「我等你好久了！快把食物拖過來嘛～」 |

> 觸發時機：OnboardingSpotlight 新手引導完成（或點「跳過」）後 400ms 延遲顯示，讓 Buddy 親口邀請玩家完成第一次餵食。

## 設計備註

- 每則文案控制在 **15–20 字**內，符合對話框空間限制
- 語氣設定：略帶撒嬌的夥伴感，自然帶出驅動行為的 hint，不強迫推銷
- 可依角色個性調整語氣方向：活潑 / 冷靜 / 中二
- 觸發條件（%數）為範本建議值，實際閾值依遊戲設計調整
- 錯誤文案取代系統 toast/alert，維持遊戲沉浸感
- **P2（掃碼）/ P4（商店/課金）例外**：這兩個畫面為獨立場景，角色不在畫面內。錯誤通知改用標準系統 toast/alert，文案語氣回歸中性系統語氣，不套用角色口吻。
