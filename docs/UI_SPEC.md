## 設計系統依據

所有畫面遵循 `ECOCO_DESIGN.md`：
- 主色 `#FF5000`（橘）/ 次色 `#060E9F`（藍）/ 輔助 `#FFCE00`（黃）
- 頁面底色 `#F7F9FC`，卡片白 `#FFFFFF`
- 字型 Noto Sans TC（中文）/ Inter（英數）
- 按鈕 CTA 一律 `rounded-full`，容器 `rounded-2xl`
- 禁止漸層

錯誤提示原則（來自 `stat_dialogue_copy.md`）：
- P1 / P9 有角色的畫面 → 角色對話泡泡
- P2（掃碼）/ P4（商店）無角色畫面 → 系統 Toast（中性語氣）

## P1 — 夥伴首頁

### 佈局結構（由上至下）

1. **Header**：ecoBUDDY Logo + 模式切換 pill（左）/ 藍色圓形用戶頭像（右）
2. **用戶問候**：`{用戶名}，歡迎回來！`
3. **角色資訊列**：角色名稱 | 月份角色 | 狀態名稱
4. **屬性圓形 Icon 列**：HP / 潔淨 / 心情（橫排三個）
5. **角色展示區**：插畫背景（靜態）+ Rive 角色動畫（Phase 1 靜態背景）
6. **右側浮動按鈕**：掃描條碼（上）/ 免費道具（下，橘色數字 Badge）
7. **對話泡泡**：角色右上方，依狀態觸發
8. **Sub-Tab 區**：食物欄 / 道具包
9. **Sub-Tab 內容區**（見下方）

### 屬性圓形 Icon

| 屬性 | Icon | Stroke 顏色 | 點擊行為 |
|------|------|------------|---------|
| HP | ❤️ | `#FF5000` | 角色對話泡泡（依 HP 狀態） |
| 潔淨 | 💧 | `#060E9F` | 角色對話泡泡（依潔淨狀態） |
| 心情 | 😊 | `#FFCE00` | 角色對話泡泡（依心情狀態） |

- 數值視覺：外圈 stroke 順時針延伸（滿 = 完整圓圈）

### 食物欄 Sub-Tab

- 格數：4 格固定（1×4 橫排）
- 顯示規則：4 格全顯示，未解鎖格顯示灰色虛線佔位（🔒）
- 庫存數字 Badge：左上角顯示，歸零後格子外觀維持正常

**互動規則**：

| 操作 | 結果 |
|------|------|
| 純點擊食物格（有庫存） | 角色對話泡泡提示「拖曳餵食」 |
| 純點擊食物格（庫存歸零） | 角色對話泡泡：「沒東西吃了 😢 去回收換食物來！」 |
| 點擊鎖定格 | 角色對話泡泡：「這個還沒解鎖，再努力一下！🔒」 |
| 拖曳食物格 → 角色展示區 | 觸發餵食動畫（P3）|
| 拖曳食物格（庫存歸零） | 角色對話泡泡提示補充 |

**Drop Zone**：角色展示區整塊（暫時保留 dragover 視覺高亮縮放 + 橘色陰影，待動畫資源到位後由動畫師角色反應取代）

### 道具包 Sub-Tab

- 佈局：與食物欄同區域切換
- 副標：「拖到角色身上即可使用 · 24 小時內有效」
- 互動規則：與食物欄拖曳邏輯相同（拖曳 → 觸發道具使用動畫）

### 角色互動

| 操作 | 結果 |
|------|------|
| 點擊角色 | 觸摸動畫（動畫師定義）+ 心情值++ |
| 拖曳食物/道具 → 角色展示區放開 | 觸發對應動畫 |

## P2 — 統一掃碼

- 全螢幕黑色相機背景
- 頂部左：`< 返回`
- 頂部中：`● 掃描條碼` 狀態 pill（橘色）
- 中央：橘色角框掃描框（非全框線）
- 機型：由 QR Code 自動判斷，不顯示在 UI
- 解析成功 → 路由：`recycling` → P2b / `refill` → P12
- 解析失敗 → 系統 Toast + `請重新對準` 橘色 CTA

**錯誤文案（系統 Toast）**：

| 狀況 | 文案 |
|------|------|
| 無法辨識 | 無法辨識 QR Code，請靠近後重新掃描 |
| 已過期 | QR Code 已過期，請重新至機台取碼 |
| 重複使用 | 此 QR Code 已使用，無法重複掃描 |
| 相機權限未開啟 | 請至系統設定開啟相機權限 |
| 網路失敗 | 網路連線失敗，請確認連線後再試 |

## P2b — 回收結果頁

- 形式：全屏頁面（對齊 P12），頂部圓角 + slide-up 動畫；Sheet Grip 指示器
- 頂部暖色區：
  - `RECYCLE COMPLETE · 回收掃碼`（橘色標籤）
  - `本次回收成功！`（大標題）
  - 時間 + 地點
  - 三格統計：投入瓶罐 / 退瓶數 / ECOCO 點數
- 中段白底：
  - `本次獲得食物` 標題
  - 食物卡片列（圖示 + ×數量 + 名稱）
  - HP 預計補充卡（`❤️ 小海龜 HP 預計補充 +X`）
- 底部按鈕：
  - 主要：`立即餵食`（橘色 `#FF5000` rounded-full）
  - 次要：`存至食物欄`（藍色 outline rounded-full）

**邊界狀況**：食物欄已滿時點「存至食物欄」→ 角色對話泡泡：「放不下了！先把現有的吃掉再說 🍖」，停留在 Sheet

## P3 — 餵食流程

- 形式：**P1 原地播放**（角色展示區直接播放餵食動畫，不跳頁）
- 觸發：拖曳食物/道具放開後立即觸發
- 動畫序列由動畫師定義，UI 層負責觸發時機

## P4 — 商店

- Header：`商店`（左）/ `€ {點數} >`（右，橘色，點擊展開點數明細 Sheet）
- 分類 Tab：食物 / 道具 / 裝飾 Phase2 / 音樂盒 Phase2（橫向滾動）
- 月底衝刺禮包 Banner：橘色，22–28 日置頂，剩餘天數顯示
- 商品 Grid：2 欄，卡片含圖示 / 品名 / 效果副標 / 點數 / 購買按鈕
  - 熱賣 badge：黃色
  - 暫時缺貨：灰色 badge + `售罄` disabled 按鈕

### 購買確認 Modal（中央彈窗）

- 商品圖示 + 名稱 + 副標
- 付款選項（同時顯示）：
  - ECOCO 點數（選中 = 橘色邊框）
  - Apple / Google Pay
- 底部：`取消`（ghost）/ `確認購買`（橘色）
- 錯誤文案（系統 Toast）：點數不足 / 付款失敗（中性語氣）

### 點數明細 Sheet（點擊右上點數觸發）

- 大字餘額顯示
- 本月累計
- 三列來源：回收掃碼 / 補充站消費 / 任務獎勵（各含本月次數 + 點數）
- `關閉` 按鈕

## P6 — 廣告 → 開箱

流程：確認底部 Sheet（今日剩 X 次）→ 廣告播放（SDK 全屏接管）→ 開箱短動畫（≈1 秒）→ 結果顯示

**確認步驟**：底部 Sheet 從 P1 彈出，不跳頁，不打斷當前畫面

**結果頁**：
- 道具圖示 + 名稱
- `立即使用`（橘色）/ `放入背包`（藍色）

- **主題**：淺色（對齊全 App 一致性）

## P9 — 道具背包

### 形式 A：P1 Sub-Tab（道具包）

- 與食物欄同區域切換
- 顯示有效道具格（免費 + 付費混列）
- 互動：拖曳到角色觸發使用動畫

### 形式 B：獨立完整頁面（P6 廣告開箱後進入）

- 分類 Tab：免費道具（X）/ 付費道具（X）
- 過期警示 Banner：`⚠ 我的玩具快消失了！快點用 ⏳`（6 小時內觸發）
- 道具格：圖示 + 名稱 + 剩餘時間（≤6h 顯示橘色警示）
- 底部 CTA：`前往夥伴頁使用`（橘色 rounded-full）**（待調整）**

## P10 — 月末選擇彈窗

- 觸發：月底前 5 天每日，或從 P7 圖鑑手動進入
- 形式：全屏深色遮罩 Modal
- 標題：`選擇你的 {月} 月夥伴`
- 副標：`從本月觸發過的狀態中挑一個鎖入年度圖鑑`
- 3×3 狀態格：
  - 已觸發：可選（點擊 = 金黃邊框高亮）
  - 未觸發：灰暗 disabled
  - 一次只能選一個
- 底部：`稍後再選`（dark outline）/ `確認鎖入`（金黃色 rounded-full）

## P12 — 補充站結果頁

- 形式：獨立全屏頁面（非 Sheet）
- 頂部暖色區：
  - `REFILL COMPLETE · 補充站消費`（藍色標籤）
  - `本次補充站消費完成！`
  - 時間 + 地點
  - 消費品項卡（品名 + 容量 + HP/潔淨雙數值）
  - 金流說明 bar：`ⓘ 金流已於補充站完成 · App 不收取費用`
- 中段：角色 Idle 動畫全身展示
- 底部：HP + 潔淨雙進度條並排（計數遞增動畫）
- CTA：`返回首頁`（橘色）
- 底部說明：`進化判斷將於動畫結束後執行 · 不與計數同步觸發`
