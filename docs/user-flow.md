## D — 現實行為 → 回收餵食 Loop（HP 驅動）

```
♻️ 回收機台投瓶
  → 機台結算（投入數 / 退瓶數）→ 機台螢幕產生 QR Code
  → 📷 P2 統一掃碼（自動偵測 machine_type = recycling）
  → 🎁 P2b 本次回收結果頁
      ├─ 本週配額未用完 → 顯示食物 + HP + 下週食物預告
      │     ├─ 立即餵食 → P3 餵食流程
      │     └─ 存入食物欄 → 返回 P1（食物欄 +N）
      └─ 本週配額已用完 → 顯示「本週食物已領完」+ HP + 下週食物預告
            └─ 完成 → HP 計入 + 返回 P1
```

### 各節點說明

**REAL WORLD — 回收機台投瓶**
- 用戶至機台投入瓶罐
- 機台結算：顯示**投入數**與**退瓶數**
- 機台螢幕產生 QR Code

**P2 — 統一掃碼**
- 開啟相機，對準任何機台螢幕 QR Code
- 解析成功 → 後端解析 `machine_type`，路由至對應結果頁：
  - `recycling` → P2b 回收結果頁
  - `refill` → P12 補充站結果頁
- 解析失敗 → 頁面提示「無法辨識，請對準機台螢幕」，繼續等待

**P2b — 本次回收結果頁**（掃碼成功後彈出）
- 依本週食物配額狀態顯示：
  - **配額未用完**：顯示本次投瓶獲得的食物種類與數量 + HP 值
  - **配額已用完**：僅顯示 HP 值，提示「本週食物已領完」
- 常態顯示下週食物預告
- 操作按鈕：
  - **配額未用完**：`立即餵食`（→ P3）/ `存入食物欄`（→ P1）
  - **配額已用完**：`完成`（→ P1，HP 計入）

**P3 — 餵食流程**
動畫序列：
```
Idle → 轉身(0.3s) → 伸手(0.5s) → 拿取(0.4s) → 吃入(0.5s) → 滿足(0.8s)
```
- HP +X（依本次投瓶數計算）
- 「再餵一份」— 食物欄有存量時可繼續

> **Phase 1 動畫採購備註**：餵食序列動畫屬**另案採購**，9 個狀態共用一套。Phase 1 Brief v1.0 僅涵蓋 Idle Loop + 點擊反應兩種 state。

**RESULT — 數值更新**
- HP 上升
- 角色外觀即時變化
- 進化狀態重新判斷
- 返回 P1 首頁

### 食物欄說明（P1 食物格）

食物採**每週配額制**：每週每種食物有數量上限；達上限後本週投瓶不再產生食物，僅 HP 增加；下週週期重置後恢復。

| 格狀態 | 視覺 | 可互動 | Badge |
|--------|------|--------|-------|
| **有庫存** | 橘色高亮邊框 | ✅ 可餵食 | 累積存量；每次餵食 -1 |
| **庫存低** | 半透明灰 | ✅ 仍可餵 | 顯示剩餘數量 |
| **🔒 未解鎖** | 虛線灰 | ❌ 鎖定 | 隱藏 |

> ※ 每週食物配額上限 TBD（→ #20）· 數量歸零需再次回收掃碼補充

## D2 — 現實行為 → 補充站購買 Loop（HP + 潔淨度驅動）

> **設計原則**：補充站掃碼只呈現「消費結果」，金流發生在現實，App 不涉及支付。
> 遊戲模式中唯一含金流的畫面為 **P4 商店**。

```
🩵 補充站現實消費（用戶已在實體補充站購買洗劑）
  → 機台螢幕產生 QR Code
  → 📷 P2 統一掃碼（自動偵測 machine_type = refill）
  → 🎁 P12 洗劑消費結果頁（HP ↑ + 潔淨度 ↑ 雙數值回饋）
  → 返回 P1
```

### 各節點說明

**REAL WORLD — 補充站現實消費**
- 用戶至補充站（ECOCO 實體據點）**已完成購買洗劑**
- 機台螢幕產生 QR Code（帶入本次消費場次資料）

**P2（refill 路徑）— 補充站掃碼**
- 同一掃碼頁，QR code 解析後 `machine_type = refill` 觸發此路徑
- 頂部標示依偵測結果動態顯示「補充站」或「回收」，給用戶視覺確認
- 解析成功 → 帶入場次資料，跳轉 P12

**P12 — 洗劑消費結果頁**（掃碼成功後顯示，結構對齊 P2b）
- 顯示本次補充站消費獲得的 **HP 值** 與 **潔淨度值**
- 角色 Idle 動畫持續播放（不新增動畫 state）
- 下方並排：HP 條（左）+ 潔淨度條（右），同步計數遞增動畫
- 動畫結束後：顯示「返回首頁」按鈕
- **進化判斷時序**：計數動畫結束後再判斷，不與動畫同步觸發

## J — 三維數值 → 進化狀態系統（全系統 36 種 · Phase 1 實作 9 種）

### 數值來源

| 數值 | 現實行為 | 外觀影響 |
|------|----------|----------|
| HP | 回收機台投瓶 + 掃碼 + 餵食 · **補充站消費** | 體型大小 / 豐潤度 |
| 潔淨度 | 補充站消費（洗劑購買） | 龜殼光澤 / 純淨度 |
| 心情值 | App 互動（廣告）· 道具購買 | 表情 / 腮紅 / 動作活潑度 |

### 進化狀態矩陣（完整系統）

```
HP（高H / 標M / 低L）
  × 潔淨（高H / 標M / 低L）
  × 心情（MAX / 高H / 標M / 低L）
= 最多 36 種型態
```

| 07 | 潔癖徹底 | L × H × L | 標準 |
| 08 | 高冷貴婦 | H × H × M | 標準 |
| 13 | 生活壓力 | M × M × L | 標準（品質基準） |
| 17 | 都市精英 | M × H × L | 標準 |
| 26 | 雍容華貴 | H × H × M | 中高難度 |
| 30 | 芝芭大舞 | M × M × 心情極高 | 特殊 |

### Rive 動畫規格（D2 · Phase 1 主包）

每個狀態必須包含：

| 動畫類型 | 規格 | 備註 |
|----------|------|------|
| Idle Loop | 3–5 秒循環：呼吸起伏 + 眨眼（3–7s 隨機）+ 四肢輕微擺動 | 主展示用 |
| 點擊反應 | 0.5–1.5 秒：歪頭 / 跳一下 / 揮手 → 自動回 Idle | 用戶點角色觸發 |
| 過渡銜接 | Idle ↔ 點擊反應自然過渡 · 禁止硬切 | — |

**不在 Phase 1 主包**：餵食動畫、道具使用動畫、進化過渡動畫（三者均另案採購）

型態改變 → 自動推播通知

| 潔淨低 | 幫我洗澡 |

| HP 低 + 潔淨低 | 雙重緊急 |

| 道具即將過期（-6h） | — |
| 月底倒數 5 天 | — |

**每月完整 Loop — 用戶旅程時間軸**

```

  → 結算 +3 天
  → 下月 1 日
```

| 節點 | 事件 |
|------|------|
| **月初 1 日** | 新月度角色解鎖 · 新食物四格開始 · 月度任務重置 |
| **每日 Loop** | 開 App → 查角色 · 回收機台 → 掃碼 · 餵食 / 廣告開箱 · 任務簽到 |
| **每週 Loop** | 累積 5 次回收 · 累積 10 次餵食 · 領取週獎勵 · 食物四格集滿 |
| **月底 -5 天** | 圖鑑 Banner 出現 · 倒數提示開始 · 衝刺禮包上架（P4）· 月度任務最後衝刺 |
| **月末選擇** | P10 彈窗觸發 · 選本月最佳狀態 · 鎖入年度圖鑑 · 或系統自動挑最高分 |
| **結算 +3 天** | 仍可進 P10 修改 · 需消耗更換次數 · 未選 → 系統自動填入 |
| **下月 1 日** | 年度圖鑑新增 1 格 · 舊角色進圖鑑存檔 · 新角色登場 |
