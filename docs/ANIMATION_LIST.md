## Phase 1 主包（隨主要採購）

每個狀態必須包含以下兩種動畫：

### Idle Loop（每狀態 1 支）
- 時長：3–5 秒循環
- 內容：呼吸起伏 + 眨眼（3–7 秒隨機）+ 四肢輕微擺動
- 用途：P1 主展示 / P12 補充站結果頁背景
- 規格：Rive 動畫，設計畫布 1024×1024，輸出至 120×120

### 點擊反應（每狀態 1 支）
- 時長：0.5–1.5 秒，播完自動回 Idle
- 內容：歪頭 / 跳一下 / 揮手（依狀態個性設計）
- 觸發：用戶點擊角色（每日 10 次上限，超過後動畫仍播放）
- 規格：Idle ↔ 點擊反應自然過渡，禁止硬切

## 另案採購（不在主包範圍）

### 餵食序列（P3）— 1 套，9 種狀態共用
動畫序列：
```
Idle → 轉身(0.3s) → 伸手(0.5s) → 拿取(0.4s) → 吃入(0.5s) → 滿足(0.8s)
```
- 觸發：拖曳食物到角色 drop zone 後放開
- 結束後：返回對應狀態的 Idle Loop

### 道具使用動畫（P9b）— 4 支，9 種狀態共用

| 道具 | 動畫動作 | 效果 |
|------|---------|------|
| 逗貓棒 | 跳躍抓取 | 心情 +15 |
| 梳子 | 梳理動作（力度較弱） | 清爽 +15 · 心情 +10 |
| 小球 | 玩球動作 | 心情 +15 |
| 零食 | 吃零食（簡版） | 精神 +15 · 心情 +15 |

### 變身過渡動畫（狀態切換）— 數量 TBD
- 觸發：三維數值變化導致 Buddy 狀態改變（稱為「變身」）
- 觸發時序：數值計算完成後（P12 為計數動畫結束後）
- UI 層負責觸發時機，動畫內容由動畫師定義

### 開箱動畫（P6）— 1 支
- 時長：≈1 秒
- 觸發：廣告播放完成後
- 結束後：顯示開箱結果（道具圖示 + 名稱）
