# ECO Buddy UI 改版 Brief

現在是能跑的 MVP,不是會讓人想打開的世界。

兩個問題:

1. 滿屏「回收、投遞、掃描、任務」,像在工作不像在陪寵物
2. ECOCO 配色用得像色票,沒有溫度

---

## 八條核心

### 1. Buddy 是一個生命,不是一個 App

判斷準則:這個設計會讓 Buddy 更像活著嗎?

### 2. 動機是「對 Buddy 好」,不是「完成任務」

「投遞、回收、掃描、打卡、任務、KPI」全部翻譯成 Buddy 世界的語言。

### 3. 環保是結果,不是訴求

不教育、不說教、不喊口號。為了 Buddy ＞ 為了地球。

### 4. 每一頁都要有 Buddy

商店、任務、圖鑑、推播、廣告、結算 —— 角落縮圖、一句對話、一個眨眼都算。

### 5. 鼓勵 ＞ 命令;陪伴 ＞ 提醒

Buddy 是「想念你」,不是「要求你」。月底倒數講「快來不及一起完成這個月」,不是「截止日逼近」。

### 6. 情緒 ＞ 資訊

少三個數據,多一個表情。

### 7. ECOCO 是 Buddy 的世界,不是廠商

用戶要感覺「我在 Buddy 的家」,不是「我在 ECOCO 的 App」。

### 8. 驚喜 ＞ 完整

每天打開要有一點沒想到 —— 表情變了、背景變了、說了新話。新鮮感是留存命脈。

- 「Phase 2、即將推出、SDK 接管」這類工程師語言
- 「ECOCO 點數」直接露出(改 Buddy 幣 / 愛心)

- 法律免責語句出現在主視覺區
