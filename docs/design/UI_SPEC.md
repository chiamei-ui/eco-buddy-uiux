## P1 — 夥伴首頁

### 佈局結構（由上至下）

1. **Header**：ecoBUDDY Logo + 模式切換 pill（左）/ 藍色圓形用戶頭像（右）
2. **用戶問候**：`{用戶名}，歡迎回來！`
3. **角色資訊列**：角色名稱 | 月份角色 | 狀態名稱
4. **屬性圓形 Icon 列**：體力 / 潔淨 / 心情（橫排三個）
5. **角色展示區**：插畫背景（靜態）+ Rive 角色動畫（Phase 1 靜態背景）
6. **右側浮動按鈕**：掃描條碼（上）/ 免費道具（下，橘色數字 Badge）
7. **對話泡泡**：角色右上方，依狀態觸發
8. **Sub-Tab 區**：食物欄 / 道具包
9. **Sub-Tab 內容區**（見下方）

### 屬性圓形 Icon

| 屬性 | Icon | Stroke 顏色 | 點擊行為 |
|------|------|------------|---------|
| 體力 | ❤️ | `#FF5A5F` | 角色對話泡泡（依體力狀態） |
| 潔淨 | 💧 | `#4A90E2` | 角色對話泡泡（依潔淨狀態） |
| 心情 | 😊 | `#FFC940` | 角色對話泡泡（依心情狀態） |

- 數值視覺：外圈 stroke 順時針延伸（滿 = 完整圓圈）

### 食物欄 Sub-Tab

- 格數：4 格固定（1×4 橫排）
- 顯示規則：4 格全顯示，未解鎖格顯示灰色虛線佔位（🔒）
- 庫存數字 Badge：左上角顯示，**每格上限 12 個**

**Badge 視覺三狀態**：

| 狀態 | Badge 顏色 | 觸發條件 |
|------|-----------|---------|
| 庫存充足 | 橘色 `#FF5000` | 庫存 ≥ 4 |
| 庫存低 | 黃色 `#FFCE00` | 庫存 1–3 |
| 未解鎖 | 灰色 + 🔒 icon | 該格尚未解鎖 |

**每週配額制**：每種食物每週上限 5 個（週三 12:00 重置）；配額達上限後投瓶僅增體力值，不新增食物格庫存。週日 12:00 起食物欄底部顯示「下週食物預告」入口。

**互動規則**：

| 操作 | 結果 |
|------|------|
| 純點擊食物格（有庫存） | 角色對話泡泡提示「拖曳餵食」 |
| 純點擊食物格（庫存歸零） | 角色對話泡泡：「沒東西吃了 😢 去帶食物回家！」 |
| 點擊鎖定格 | 角色對話泡泡：「這個還沒解鎖，再努力一下！🔒」 |
| 拖曳食物格 → 角色展示區 | 觸發餵食動畫（P3）|
| 拖曳食物格（庫存歸零） | 角色對話泡泡提示補充 |

**Drop Zone**：角色展示區整塊（dragover 視覺高亮縮放 + 橘色陰影，待動畫資源到位後由動畫師角色反應取代）

**從 P2b「先放食物欄」返回後的入場動態**：

當用戶在 P2b 點擊「先放食物欄」返回 P1 時，P1 食物欄需呈現以下動態，持續至用戶互動或 3 秒後自動消失：

| 元件 | 動態效果 | 規格 |
|------|---------|------|
| 新增食物的格子 | 橘色光暈脈衝 `ring-pulse`：外框從 `#FF5000` → 透明 → `#FF5000`，循環 2 次 | 持續約 2s，完成後回 Badge 正常高亮態 |
| Badge 數字 | 縮放 pop：`scale 0.8 → 1.2 → 1.0`，數字同步更新為最新庫存 | 單次，duration 400ms |
| Buddy 對話泡泡 | 顯示「幫我存好了！等你準備好再給我～」 | 10 秒自動消失，可點 ✕ 提早關閉 |
| Sub-Tab 焦點 | 若用戶當前在「道具包」Tab，自動切換到「食物欄」Tab | 切換無動畫，食物欄直接入場 |

> 設計注意：若本次存入的食物跨越「庫存低 → 庫存充足」閾值（庫存從 1–3 跳至 ≥ 4），Badge 顏色需在 pop 動畫完成後從黃色 `#FFCE00` 切換至橘色 `#FF5000`。

### 道具包 Sub-Tab

- 佈局：與食物欄同區域切換
- 副標：「拖到角色身上即可使用 · 24 小時內有效（免費道具）」
- 右上角「**管理 ›**」按鈕 → 跳轉 P9 道具背包
- 互動規則：與食物欄拖曳邏輯相同（拖曳 → 觸發道具使用動畫）

### 免費道具浮動按鈕

- 位置：右側浮動按鈕下方（橘色圓形）
- Badge：橘色數字，顯示「今日剩餘次數 / 5」格式（如 `3`）
- 次數用完：Badge 顯示 0，按鈕進入 disabled 樣式
- 點擊行為：彈出底部 Sheet → P6 廣告流程

### 角色互動（觸碰 Buddy）

| 操作 | 結果 |
|------|------|
| 點擊 Buddy（當日 < 10 次） | 點擊反應動畫（歪頭 / 跳一下 / 揮手）+ 心情值 +1 |
| 點擊 Buddy（當日 ≥ 10 次） | 點擊反應動畫照常播放，心情值不再增加 |
| 拖曳食物/道具 → 角色展示區放開 | 觸發對應動畫 |

> **設計注記（D5）**：達 10 次上限後動畫仍播放，避免「點不動」的死感。前端追蹤當日次數，後端最終核對心情上限。

## P2 — 統一掃碼

- 全螢幕黑色相機背景
- 頂部左：`< 返回`
- 頂部中：動態狀態 pill（橘色）
- 中央：橘色角框掃描框（非全框線）
- 機型：由 QR Code 自動判斷，掃描過程不在 UI 顯示機型

### 頂部動態標示

| 狀態 | Pill 文字 | 觸發條件 |
|------|----------|---------|
| 對準中 | `● 對準中` | 預設等待狀態 |
| 解析失敗 | `✕ 無法辨識` | QR Code 解析失敗 |
| 偵測為回收 | `♻ 偵測為回收` | `machine_type = recycling` |
| 偵測為補充站 | `💧 偵測為補充站` | `machine_type = refill` |

- 解析成功後路由：`recycling` → P2b / `refill` → P12
- 解析失敗：相機持續等待，不離開 P2

**錯誤文案（系統 Toast）**：

| 狀況 | 文案 |
|------|------|
| 無法辨識 | 無法辨識 QR Code，請靠近後重新對準 |
| 已過期 | QR Code 已過期，請重新至機台取碼 |
| 重複使用 | 此 QR Code 已使用，無法重複掃描 |
| 相機權限未開啟 | 請至系統設定開啟相機權限 |
| 網路失敗 | 網路連線失敗，請確認連線後再試 |

## P4 — 商店

### Header 結構

- 左：`商店` 標題
- 右：`💎 {愛心數} >`（橘色文字，點擊展開愛心來源 Sheet）

### 分類 Tab

橫向滾動 Tab 保留品類結構（食物 / 玩具 / 裝扮 / 氣氛…），以卡片 Badge 區分貨幣，不設雙軌入口 Tab。

### 商店雙軌制（D6）

| 貨幣 | Badge 樣式 | 典型商品 |
|------|-----------|---------|
| 💎 愛心 | 橘色文字右上 Badge | 基礎食物補給包、逗貓棒 / 小球 / 梳子 / 零食、清潔用品 |
| 💳 NT$ | 藍色文字右上 Badge | 月底衝刺禮包 NT$199、月度通行證 NT$149、稀有限定裝飾 |

- 愛心與現金不互換、不互買
- 愛心不足時 Modal 提示愛心不足，不自動切換現金選項

### 月底衝刺禮包（22–28 日置頂）

- **顯示條件**：當月 22–28 日
- **位置**：商店頁最頂部，其他商品之前
- **樣式**：橘色橫幅卡 + `倒數 N 天`徽章（`#FFCE00`）
- 非 22–28 日：自動下移至一般列表

### 商品卡片

- 2 欄 Grid，卡片：圖示 / 品名 / 效果副標 / 貨幣 Badge + 價格 / 購買按鈕
- 熱賣 Badge：黃色 `#FFCE00`

**售罄狀態**：
- 卡片整體半透明灰（`opacity-50` + `grayscale`）
- 「Buddy 已經吃過了」標籤疊加
- 點擊無響應，不開啟購買 Sheet

### 購買確認（底部 Sheet）

點擊可購買卡片 → 底部 Sheet（非中央彈窗）：

**愛心版**：
- 商品圖示 + 名稱 + 副標
- 當前愛心餘額 + 扣款後剩餘
- `取消`（ghost）/ `確認購買`（橘色 `rounded-full`）

**IAP 版**：
- 商品圖示 + 名稱 + NT$ 定價
- Apple Pay / Google Pay 選項
- `取消`（ghost）/ `確認購買`（橘色 `rounded-full`）

### 愛心餘額 Sheet（點擊 Header 右上觸發）

- 大字餘額顯示
- 三列來源：帶食物回家次數 + 累積 / 補充站消費 + 累積 / 今日陪伴獎勵 + 累積

## P9 — 道具背包

- 與食物欄同區域切換
- 顯示有效道具格（免費 + 付費混列）

### 形式 B：獨立完整頁面

- 分類 Tab：免費道具（X）/ 付費道具（X）

| 道具 | 效果 | Rive State |

| 梳子 | 潔淨 +15 · 心情 +10 | `Clean` |
| 零食 | 體力 +15 · 心情 +15 | `Feed` |

### 空背包狀態

### 推播通用規則

- 每維度（體力 / 潔淨 / 心情）每日最多推播 1 次
