## 通用替換規則(全 App 搜尋取代)

| 找到 | 換成 |
|------|------|
| 回收 | 帶 Buddy 食材 / 給 Buddy / 為 Buddy |
| 投遞 | (依語境改) |
| 掃描 / 掃碼 | 帶禮物回家 |
| 任務 | 陪伴 / 今日 |
| 完成 | 一起做到 |
| 點數 | 點數（保留，不改為愛心）|
| 寵物 | Buddy |
| 角色 | Buddy |
| HP | 體力 |
| 精神（舊）| 體力 |
| 潔淨度 | 潔淨 |
| 清爽（舊）| 潔淨 |
| 心情值 | 心情(保留) |
| 屬性 | 狀態 |
| 進化 | 變身 |
| 投入 | 帶回 |
| 餵食次數 | 用餐 |

> **禮物 vs 食物 邊界規則**：「帶禮物回家」指**投瓶取得行為**（必得體力＋潔淨、有機會換到食物）；「食物」一詞保留給**資源本身**——食物欄、餵食、週配額、食物效果值。判準：講動作／來源／累積次數 → 禮物；講吃的東西／欄位／配額／效果 → 食物。

## 命名邏輯三原則

1. **動詞改情感** — 「掃描、投遞、餵食」改成「帶回家、給 Buddy、陪用餐」
2. **數字加溫度** — 「238 次」改「238 次帶禮物回家」（動作＋情感，避開禁用詞「回收」）
3. **狀態變對話** — 「狀態:日常待機」改 Buddy 自己說「今天有點想你」
