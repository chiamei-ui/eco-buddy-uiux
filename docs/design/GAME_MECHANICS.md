# ECO Buddy — 遊戲數值規格

> **用途**：所有數值的唯一來源，前端 / 後端 / PM 共用。
> **更新規則**：PM 決策 → 先改 `docs/decisions/CURRENT.md` → 再同步此檔案。
> **Last updated**: 2026-05-29

---

## 1. 三維數值定義

| 數值名稱 | 色彩 | HEX | Emoji | 驅動行為 |
|---------|------|-----|-------|---------|
| 體力 | 暖紅 | `#FF5A5F` | ❤️ | 回收投瓶（依品項）、補充站消費、食物餵食 |
| 潔淨 | 水藍 | `#4A90E2` | 💧 | 補充站消費 |
| 心情 | 暖黃 | `#FFC940` | 😊 | 觸碰角色、廣告道具、課金道具 |

### 每日自然衰減
- 三維數值均為每 24 小時 -5%（後台結算，依未登入天數累積）
- 7 天不回來 ≈ 剩 70%

### 推播通知閾值
- 任一數值 < 30% → 觸發推播（每維度每日最多 1 次）

## 2. 回收機台 → 體力 / 潔淨換算

### 收瓶機（#3 v2 定案，2026-05-29，比照 ECOCO 點數計算方式）

| 品項 | 體力 |
|------|------|
| PET 寶特瓶 / 鋁罐 / HDPE 牛奶瓶 | +2 / 個 |
| PP 塑膠杯 | +1 / 個 |
| 退瓶 | 不計入體力 |

### 電池機（#3 定案）

| 品項 | 體力 |
|------|------|
| 1號 / 2號乾電池 / 9V 方形乾電池 | +10 / 顆 |
| 3號至6號乾電池 | +5 / 顆 |

> ⏳ **退瓶是否影響潔淨或其他維度**：待 PM 確認
> - 已知方向：退瓶可能負向影響潔淨（比例參考：進瓶+2 / 退瓶-1，非實際數值）
> - PM 確認前：UI 與後端不實作此邏輯

---

## 3. 補充站消費 → 體力 / 潔淨換算（#3 定案）

每消費 NT$10 = 體力 **+10** + 潔淨 **+10**（約 1 元 / 1+1）

---

## 4. 觸碰角色 → 心情（#2 定案）

- 每次點擊 Buddy → 心情 +1
- 每日上限 10 次

---

## 5. 食物每週配額（#20 定案）

- 每週配發一種食物，每人每種食物上限 5 個（#5 上限 12 個/格）
- 重置時間：週三 12:00
- 下週食物預告：週日 12:00 開始顯示
- 配額用完後繼續投瓶：僅計算體力 / 潔淨，不產生食物
- 食物種類由行銷部手動排程

---

## 6. 道具效果（#24 ⏳ 數值後台可設定）

> ⚠️ 以下為暫定參考值，正式數值需後台設定介面管理，前端不寫死。

| 道具 | 暫定效果 |
|------|---------|
| 逗貓棒 | 心情 +15 |
| 小球 | 心情 +15 |
| 梳子 | 潔淨 +15 · 心情 +10 |
| 零食 | 體力 +15 · 心情 +15 |

**工程師注意**：後台需為每個道具提供獨立的數值設定欄位（體力值、潔淨值、心情值）。
