## 四、按鈕

### 主按鈕(Primary)
- 底色:`#FF5000` → `#FF7A33` 漸層(135°)
- 文字:`#FFFFFF`,Noto Sans TC 16pt 700
- 圓角:12px 或 999px(pill)
- 高度:48pt
- 陰影:`0 4px 12px rgba(255,80,0,0.25)`

### 次按鈕(Secondary)
- 底色:透明 / `#FFFFFF`
- 邊框:1.5px `#FF5000`
- 文字:`#FF5000`,16pt 600
- 高度:48pt

### 禁用(Disabled)
- 底色:`#E5E5E5`
- 文字:`#999999`
- 不要降低透明度,直接換色

### 警示(Warning)
- 底色:`#FFCE00` → `#FFB800` 漸層
- 文字:`#060E9F`

---

## 五、卡片

### 標準卡片
- 底色:`#FFFFFF`(在奶油膚底色上)
- 圓角:16px
- 陰影:`0 2px 8px rgba(0,0,0,0.06)`
- 內距:16px
- 不用邊框

### 強調卡片(Hero 卡)
- 底色:`#FF5000` → `#FF7A33` 漸層 or `#FAE0B8` → `#FFCE00` 漸層
- 圓角:24px
- 陰影:`0 8px 24px rgba(255,80,0,0.15)`
- 內距:24px

### 商品卡
- 底色:`#FFFFFF`
- 圓角:16px
- 商品圖佔上 60%,下 40% 為資訊區
- 角落貼標(熱賣 / 缺貨)用 `#FF5000` 圓角 8px

| 個人主頁 | 頂部 Buddy 半身陪伴 |
| 推播 | Emoji 用 Buddy 表情包 |

## 九、Buddy 對話泡泡

- 形狀:雲朵狀 / 圓角矩形 + 三角指向
- 底色:`#FFFFFF` + 陰影 `md`
- 文字:14pt 400 `#333333`
- 出現時機:停在主畫面 3 秒後 / 屬性低於 30 時 / 進入新頁面

**對話池範例(主畫面)**
- 今天有點想你～
- 我餓了
- 想出去玩~
- 摸摸我嘛
- (心情高)今天好開心
- (心情低)…
- (剛餵食)好飽~謝謝你

## 十、Icon 系統

### 規則
- 統一風格:扁平 + 微立體(不要混搭 emoji 與 3D)
- 尺寸三階:16 / 24 / 32px
- 線條粗細:2px
- 色彩:單色 or 雙色,不超過 3 色

### 四大類

**1. 屬性 Icon**
- 精神 / 清爽 / 心情(三種,各 3 階表情變化)

**2. 食物 Icon**
- 每月 4 種(W1-W3 普通 + W4 稀有)
- 統一斜 15° 視角

**3. 道具 Icon**
- 玩具類 / 裝飾類 / 環境類 / 清潔類
- 加柔和陰影

**4. 操作 Icon**
- 掃描 / 餵食 / 觸摸 / 廣告 / 任務 / 圖鑑 / 商店 / 設定
- 線稿風,可填色

### 禁用
- 系統 emoji(🔥💎📊⏰)
- Material Icons / Font Awesome(風格不符)
- 與 Buddy 風格衝突的寫實圖

## 十一、動效規範

### 微互動

| 元素 | 動效 | 時長 | 緩動 |
|------|------|------|------|
| 按鈕點擊 | scale 0.95 → 1 | 150ms | ease-out |
| 卡片點擊 | scale 0.98 + shadow 加深 | 200ms | ease-out |
| Tab 切換 | 滑動 + fade | 300ms | ease-in-out |
| 數字跳動 | spring 彈性 | 600ms | spring |
| 屬性條增加 | 流體填充 + 微閃光 | 800ms | ease-out |
| 愛心 +N 出現 | 從點擊處飄起 + fade | 1000ms | ease-out |

### 場景動效

**進入畫面**
- 元素由下往上 stagger 出現(每個延遲 80ms)
- 整體 400ms 完成

**Buddy 待機**
- 呼吸動畫:scale 1.0 ↔ 1.02,3 秒循環
- 隨機眨眼:每 4-7 秒一次
- 隨機小動作:每 20-30 秒(看左看右 / 抖耳朵 / 嘆氣)

**慶祝時刻**
- 粒子噴發(愛心 / 星星)
- Buddy 跳起 1 次(高度 30px,彈性緩動)
- 數字跳動 + 螢幕微震 100ms

## 十二、背景系統

### 主畫面背景

**時間切換**(自動)
- 06:00-11:00:晨光,奶油膚 → 淡橘漸層
- 11:00-17:00:午後,淡藍 → 淡黃漸層
- 17:00-20:00:黃昏,橘 → 紫漸層
- 20:00-06:00:夜晚,深藍 → 紫漸層,加星點

**元素層次**
- 遠景:雲、樹、建築剪影(5% 透明度)
- 中景:地面、低矮裝飾
- 前景:Buddy
- 互動層:對話泡泡、UI

## 十三、空狀態(Empty State)

不要只放灰色文字「目前沒有資料」。

| 場景 | 設計 |
|------|------|
| 沒道具 | Buddy 抱著禮物盒等待,文案「Buddy 還沒有玩具,去看看吧」 |
| 沒任務 | Buddy 趴著睡覺,文案「Buddy 累了,明天再來」 |
| 圖鑑空 | Buddy 拿著日誌本,文案「快收集第一個 Buddy 吧」 |
| 載入中 | Buddy 跳繩動畫,不要用菊花轉圈 |

---

## 十四、推播樣式

- 圖示:Buddy 頭像(60×60 圓形)
- 標題:14pt 600
- 內文:13pt 400
- 角落小標(HP 低 / 月底倒數 / 道具到期):10pt,`#999999`

---

## 十五、容易踩雷的地方

1. **不要用純白底**,大面積一律奶油膚或淡奶油
2. **不要用系統 emoji**,Icon 全部自製
3. **不要用 Material Design 那種太工程的卡片陰影**,要更柔
4. **不要把 ECOCO Logo 放太大**,Buddy 是主角不是品牌
5. **不要用警示紅 `#FF0000`**,要警示用 `#FFCE00` 橘黃系
6. **不要用銳利的直角卡片**,圓角是 ECOCO 視覺語言
7. **不要讓 Buddy 缺席任何一頁**
