## Context

P2b 與 P12 共用 `.rs-title`，並以外部 SVG `<img>` 顯示。兩份 SVG 已包含中央光暈、12 道放射光、標題字與星星，因此可直接利用既有向量圖層製作分段動畫。

## Goals / Non-Goals

**Goals:**
- 讓光暈、放射光、標題與星星依序出現。
- P2b 與 P12 使用一致節奏。
- 不增加第三方動畫套件與載入成本。
- 提供減少動態效果模式。

**Non-Goals:**
- 不取代 Buddy 的 Rive 動畫。
- 不修改結果頁資料、文案或後端流程。
- 不將 SVG 轉換為 Lottie。

## Decisions

- 動畫寫入 SVG 內部樣式。外部 `<img>` 無法由頁面 CSS 選取 SVG 內部 path，內嵌樣式可維持現有引用方式。
- 依目前 path 順序分層：第 1 個 path 為光暈、第 2–13 個為放射光、第 14–21 個為標題、第 22 個起為星星。
- 放射光以 SVG viewBox 中心為旋轉原點，先縮放淡入再旋轉回正。
- 標題與星星採短促 overshoot，整體主要演出控制在約 1 秒內。
- 頁面原有整張 `.rs-title` 動畫移除，避免外層縮放與 SVG 內層動畫互相疊加。

## Risks / Trade-offs

- [SVG path 順序日後被設計工具重排] → 在兩份 SVG 內標註動畫分層註解，重匯出時需重新確認 path 範圍。
- [瀏覽器快取舊 SVG] → 開發驗證時重新載入頁面；正式資產發布由檔案版本或部署雜湊處理。
- [過多動態造成不適] → `prefers-reduced-motion: reduce` 時取消所有動畫。
