## Why

`docs/user-flow.md` 在 2026-05-28 升版至 v1.7，吸收了 2026-05-27 PM 決策（#2/#3/#4/#5/#16/#17/#18/#19/#20/#21）。目前各頁面 UI（hi-fi / wireframe）尚未對齊新的數值換算、食物配額制、衰減規則、推播入口、Tab 文案與商店雙軌制，導致流程文件與實作畫面分歧。本次變更將 v1.7 流程逐項落地到 UI 規格與畫面，確保 Phase 1 快閃驗證上線時與 PM 定稿一致。

## What Changes

- **P2b 回收結果頁**：套用新換算公式（杯子 +1 / 寶特瓶・鋁罐・牛奶瓶 +2 / 電池 1-2 號 +10 / 其他電池 +5 / 退瓶不計），新增「配額已用完」狀態 UI 與下週食物預告區，加上 ℹ️ 換算說明摺疊區。
- **P12 補充站結果頁**：套用 NT$10 = 精神 +10 + 清爽 +10 公式，並排雙數值計數動畫，加上 ℹ️ 換算說明摺疊區，進化判斷時序改為計數動畫結束後再觸發。
- **P2 統一掃碼**：自動偵測 `machine_type` 並依 recycling / refill 動態切換頂部標示，路由至 P2b 或 P12。
- **P1 夥伴首頁**：食物欄每格上限改為 12，新增觸碰角色 → 心情 +1（每日上限 10 次）互動與動畫 state。
- **食物配額制**：每種食物每週上限 5 個、週三 12:00 重置、週日 12:00 起常態顯示下週食物預告、配額用完僅加 HP。
- **衰減規則**：三維每日 -5% 後台結算；推播閾值 < 30%，每維度每日最多 1 次。
- **推播入口**：統一由一般模式通知中心發出，點擊推播 → 跳轉遊戲模式對應頁。
- **Tab 與屬性文案**：底部 Tab「任務 → 今日陪伴」、「圖鑑 → 夥伴日誌」；屬性「HP → 精神」、「潔淨度 → 清爽」全站替換。
- **P5 今日陪伴**：日常任務獎勵簡化為食物 1 個 + 心情 +3（即時發放），不再發愛心。
- **P4 商店雙軌制**：分為「愛心消費區」與「真實金流 IAP 區」，點數與現金不互換；月底衝刺禮包 22–28 日置頂；卡片明確標示「💎 愛心」或「💳 NT$」。
- **P9b 道具效果**：對齊新數值（逗貓棒 / 小球 心情 +15；梳子 清爽 +15・心情 +10；零食 精神 +15・心情 +15）。

## Capabilities

### New Capabilities

- `scan-result-ui`: P2 統一掃碼、P2b 回收結果頁、P12 補充站結果頁的畫面結構、換算公式、配額狀態與摺疊說明區。
- `partner-home-ui`: P1 夥伴首頁的食物欄、道具欄、屬性條、觸碰互動、食物配額顯示與下週預告。
- `daily-companion-ui`: P5 今日陪伴頁（原任務頁）的任務分類、獎勵結構與文案。
- `shop-dual-track-ui`: P4 商店的愛心 / IAP 雙軌分區、月底衝刺禮包置頂、卡片貨幣標示。
- `item-effects-ui`: P9 道具背包與 P9b 使用動畫的效果數值顯示。
- `decay-and-push-ui`: 三維衰減呈現規則與推播文案、入口（統一由一般模式通知中心）對應頁面。
- `terminology-rename`: 全站文案 / Tab / 屬性名稱替換（任務 → 今日陪伴、圖鑑 → 夥伴日誌、HP → 精神、潔淨度 → 清爽）。
