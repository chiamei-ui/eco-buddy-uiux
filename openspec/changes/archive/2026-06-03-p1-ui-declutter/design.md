## Context

P1 首頁目前在角色展示區上方有「用戶問候列」，在食物欄與道具包 Sub-Tab 各有一行副標文字，兩者都是靜態說明性文字，與 Buddy 對話泡泡的即時引導重複。道具格在 P1 層級缺少時效視覺規格（⏰ icon、過期灰化），用戶無法在不進 P9 的情況下感知道具即將消失。食物格與道具格目前直接在卡片上顯示效果值，導致卡片資訊密度過高。Header 頭像目前為純圓形，無可點擊視覺線索。

## Goals / Non-Goals

**Goals:**
- 減少 P1 靜態說明性文字，讓畫面空間讓位給 Buddy 與即時互動
- 補齊 P1 道具格時效視覺規格（規格缺口）
- 將效果值從卡片本體移入 ℹ️ Bottom Sheet，降低視覺噪音
- 以最小改動強化 Header 頭像可點擊性（不改變路由或結構）

**Non-Goals:**
- 不重新設計 P1 整體佈局
- 不變更道具有效期的商業規則（仍為免費 24h / 付費 7 日 / 永久）
- 不在 P1 新增道具操作入口（唯一入口仍為拖曳至 Buddy）
- 不改 ℹ️ Sheet 之外的 P4 商店卡片呈現

## Decisions

**D1 — 移除問候列，不補替代文字**
問候列原本的情感功能（Buddy 等你）由對話泡泡承載（body 狀態觸發），移除後不補任何靜態替代文字，避免新增相同噪音。

**D2 — Sub-Tab 副標文字全部移除，不轉移至 Tooltip**
副標與「點擊格子 → Buddy 泡泡引導」完全重複。Tooltip 需要額外互動才能看到，反而降低首次引導效率；改由泡泡在首次點擊時自然引導。

**D3 — 道具格時效臨界值：P1 用 ≤24h，P9 用 ≤6h**
P1 是輕掃覽場景，用戶不需要精確倒數，只需知道「今天要用」；P9 是管理場景，6h 精確警告有意義。兩層閾值分工明確，不統一。

**D4 — 已過期道具保留卡片 24h 後自動移除**
立即消失會讓用戶困惑「道具去哪了」；保留灰化卡片 + Buddy 泡泡「嗚… 這個不見了 😔」可作為軟通知，24h 後靜默移除。

**D5 — ℹ️ icon 位置：卡片右上角，⏰ / ✕ 共用同一角落**
優先級：✕（已過期）> ⏰（即將過期）> ℹ️（一般）— 三種狀態互斥，同一位置依狀態切換，不堆疊 icon。

**D6 — 頭像可點擊線索：橘色 border + ⚙ overlay，不改為 Pill**
Pill 佔用 Header 橫向空間，可能擠壓模式切換器。橘色 border 符合設計系統主色，⚙ overlay 是通用「設定入口」慣例，改動最小且可逆。

## Risks / Trade-offs

- **⏰ / ✕ / ℹ️ 三態 icon 空間共用**：卡片格子小（約 72×72px），右上角 icon 需確保 tap target ≥ 24px，避免誤觸拖曳。→ 實作時 icon 用絕對定位 + `z-index` 覆蓋，點擊事件 `stopPropagation` 避免觸發拖曳。
- **移除副標後首次用戶引導**：新用戶可能不知道要拖曳。→ 點擊格子時 Buddy 泡泡即時引導，與移除前的副標效果等同，且更有情感感。
- **Bottom Sheet 效果值需與 GAME_MECHANICS.md 同步**：數值若日後調整，Sheet 必須跟著更新。→ 由 GAME_MECHANICS.md 作為唯一數值來源，前端不 hardcode，從資料層帶入。
