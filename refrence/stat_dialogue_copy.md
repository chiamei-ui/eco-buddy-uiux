# 數值 Icon 對話框文案範本

點擊數值 icon 後，由角色對話框跳出 icon 說明與當前數值對應文案。

---

## HP 生命值
> 驅動行為：回收行為 · 補充站消費

| 狀態 | 觸發條件 | 文案 |
|------|----------|------|
| 高   | HP ≥ 70% | 「今天回收了瓶子，我整個活起來了！💪」 |
| 中   | HP 30–69% | 「有點累… 去補充站補個能量吧？」 |
| 低   | HP < 30% | 「快沒力了！快去回收或補充站救我 😫」 |

---

## 錯誤操作 / 邊界狀況對話框

> 系統錯誤或邊界行為發生時，由角色對話框取代冷冰冰的 toast/alert，維持遊戲沉浸感。

---

### 掃碼相關（P2）

| 狀況 | 觸發條件 | 文案 |
|------|----------|------|
| QR Code 無法辨識 | 模糊 / 距離過遠 | 「看不清楚啦！靠近一點再掃 📷」 |
| QR Code 已過期 | 機台碼逾時 | 「這個碼好像過期了，請重新到機台取碼」 |
| QR Code 重複使用 | 同一碼掃第二次 | 「欸這個我已經吃過了喔 🐢 不能重複喔」 |
| 相機權限未開啟 | 系統拒絕相機存取 | 「讓我看看嘛！記得開相機權限 👀」 |
| 網路連線失敗（掃碼驗證） | API 無回應 | 「訊號不太好… 等等再試試？」 |

| 月末最後一天警示 | 月底最後 24h | 「今天是最後機會！快來幫我選！⏰」 |

## 設計備註

- 每則文案控制在 **15–20 字**內，符合對話框空間限制
- 語氣設定：略帶撒嬌的夥伴感，自然帶出驅動行為的 hint，不強迫推銷
- 可依角色個性調整語氣方向：活潑 / 冷靜 / 中二
- 觸發條件（%數）為範本建議值，實際閾值依遊戲設計調整
- 錯誤文案取代系統 toast/alert，維持遊戲沉浸感
